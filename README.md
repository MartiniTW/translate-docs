# 純繁・簡體轉繁體

適用於 Google Chrome 與 Microsoft Edge 桌面版的離線簡繁字形轉換擴充功能。保留原本用語，例如「软件 → 軟件」，不改寫句子或替換成其他地區用語。

## 使用方式

1. 安裝後重新整理要閱讀的一般網頁。
2. 點開工具列上的「純繁」，按「啟用此網站的簡 → 繁」。
3. 選擇會記住在該主機名稱；之後造訪、同網站其他分頁及動態新增文字會套用轉換。
4. 要回到原文時，按「關閉轉換，還原原文」。網站已自行更新的文字不會被舊原文覆蓋。

網站設定依精確主機名稱區分，例如 `example.com` 與 `www.example.com` 分開；同主機的 HTTP／HTTPS 網頁與不同連接埠共用設定。可支援的嵌入框架跟隨最外層網站設定。

## 0.5.0 快捷鍵、網站管理與備份

以下功能適用於 0.5.0；各商店可下載的版本以其上架狀態為準。

### 快速切換目前網站

- 按 `Ctrl+Shift+Y`；macOS 為 `Command+Shift+Y`。與面板開關相同，會影響同主機其他分頁與後續造訪。
- 面板與管理頁顯示實際綁定的快捷鍵。若未綁定或按鍵被占用，可按「設定快捷鍵」自行調整；純繁不會覆蓋其他擴充功能的快捷鍵。
- 工具列綠色「繁」表示已啟用，灰色「原」表示已停用；這是模式狀態，不代表整頁已轉換完成。
- 載入中、受限制或無法確認的頁面不顯示狀態字；操作失敗顯示「!」，將滑鼠移到圖示可查看原因。需要重新整理的頁面不會因快捷鍵而變更網站設定。

### 管理已設定的網站

點面板的「管理網站與備份」，在獨立分頁搜尋網站，或篩選全部／已啟用／已關閉。可輸入主機名稱或貼上 HTTP／HTTPS 網址，確認顯示的主機名稱後按「新增並啟用」。只保存主機名稱，不保存網址的路徑、查詢參數、連接埠與片段；不接受帳密、萬用字元或其他協定。

**0.5.0 關閉網站後會保留清單項目；按「刪除」才移除該網站設定並停止轉換。** 變更會同步套用同主機已開啟的分頁與可支援框架，不影響其他網站共用的例外字。升級會保留既有設定，但無法復原舊版關閉時已刪除的網站。

### 備份與移轉設定

管理頁的「匯出目前設定」會下載 JSON，可在 Chrome 與 Edge 之間移轉。檔案只包含主機名稱、開關與全域例外字，不包含網頁文字、暫存、完整網址、造訪時間或瀏覽器管理的快捷鍵綁定。

1. 選擇 JSON 檔案，再選「合併」或「取代」。匯出與匯入檔案皆以 1 MiB 為上限。
2. 按「預覽變更」，核對新增、移除網站及開關、例外字的差異。
3. 按「確認合併」或「確認取代」才保存；預覽後若其他入口改動設定，需重新預覽。

| 匯入方式 | 行為 |
| --- | --- |
| 合併（預設） | 加入不存在的網站，同名網站保留目前開關；加入備份中的有效例外字，空清單不清除目前例外字。備份若沿用預設，會合併目前版本的預設字。 |
| 取代 | 完整採用備份，移除備份以外的網站；已關閉網站與明確空例外清單也會還原。 |

備份中的 `exceptionCharacters: null` 表示沿用預設字，`""` 表示刻意清空。錯誤格式、未知版本或無效資料會整份拒絕，不部分套用。設定與檔案皆在本機處理，不使用雲端同步。已下載的備份由你自行保管或刪除，移除擴充功能不會刪除備份檔案。

## 功能與限制

- 預設不轉換，由使用者選擇網站。
- 轉換程式與字庫隨套件提供，在本機處理文字，不上傳網頁內容。
- 只修改一般 HTML 文字節點，不插入包裝標籤、不改 CSS 或表單值。
- 略過輸入框、可編輯區、程式碼及網站指定不要翻譯的區域。
- 自 0.4.0 起支援 open Shadow DOM 元件中的文字，包括動態新增的評論與回覆；後建立的元件可能稍晚完成轉換。
- 不支援圖片、Canvas、SVG、MathML、closed Shadow DOM、瀏覽器內建頁、商店及內建 PDF 檢視器等受限制內容。
- 網站字型與替代字型仍可能影響字寬和換行，無法保證所有網站版面完全相同。
- 跨標籤的詞語與少數一簡多繁字可能選錯；過長的單一文字節點會保留原文。

## 0.3.0 例外字設定

更新至 0.3.0 後，可在面板展開「例外字」。沒有已儲存清單時，預設保留 **台、裏、祕、牀、峯、羣、晒、污、喫、纔** 10 字。例如「台湾」轉成「台灣」，原本的「臺灣」仍保持「臺灣」；「祕密」保留祕，「秘密」也不會反向改寫。

這是本工具參考教育部字條與實際字庫行為選出的閱讀偏好，不是教育部公布的免轉換清單。字典亦收錄部分簡化字，因此不將整份異體字表匯入；「国、学、体、发」等仍正常轉換。參見教育部 [編輯體例](https://dict.variants.moe.edu.tw/page.jsp?ID=77&la=0)、[祕字條](https://dict.variants.moe.edu.tw/dictView.jsp?ID=30675&la=0) 與 [晒字條](https://dict.variants.moe.edu.tw/dictView.jsp?ID=19908)。

- 輸入想保留的中文字，按「新增」或 Enter；可一次新增多字，重複字自動合併。
- 每個字顯示成「台 ×」等獨立標籤，點 × 只移除該字。全部移除後恢復完整字庫轉換。
- 可搜尋已保留的字，查看符合數／總字數；搜尋不改動清單，大量字元會在固定高度內捲動。
- 「加入預設字」補上缺少的預設字，保留其他自訂字與尚未新增的輸入。
- 設定全站共用，只保存在本機；新增／移除立即套用已啟用的分頁。未啟用的網站保持原狀。

**升級會保留已儲存的清單**，包括舊版的「台」、空清單與自訂字。想採用新版選字時，按一次「加入預設字」。例外是全字保留，例如「台風」的台也會保留，並非只針對「台灣」的詞組規則。
