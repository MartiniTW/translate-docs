# 純繁・簡體轉繁體

Microsoft Edge 桌面版的離線簡繁字形轉換擴充功能。保留原本用語，例如「软件 → 軟件」，不改寫句子或替換成其他地區用語。

## 使用方式

1. 安裝後重新整理要閱讀的一般網頁。
2. 點開工具列上的「純繁」，按「啟用此網站的簡 → 繁」。
3. 選擇會記住在該主機名稱；之後造訪、同網站其他分頁及動態新增文字會套用轉換。
4. 要回到原文時，按「關閉轉換，還原原文」。網站已自行更新的文字不會被舊原文覆蓋。

## 功能與限制

- 預設不轉換，由使用者選擇網站。
- 轉換程式與字庫隨套件提供，在本機處理文字，不上傳網頁內容。
- 只修改一般 HTML 文字節點，不插入包裝標籤、不改 CSS 或表單值。
- 略過輸入框、可編輯區、程式碼及網站指定不要翻譯的區域。
- 不支援圖片、Canvas、SVG、MathML、Shadow DOM、瀏覽器內建頁、商店及內建 PDF 檢視器等受限制內容。
- 網站字型與替代字型仍可能影響字寬和換行，無法保證所有網站版面完全相同。
- 跨標籤的詞語與少數一簡多繁字可能選錯；過長的單一文字節點會保留原文。

## 0.2.1 例外字設定

更新至 0.2.1 後，可在面板展開「例外字」。預設保留「台」，例如「台湾」轉成「台灣」，原本的「臺灣」仍保持「臺灣」。

- 輸入想保留的中文字，按「新增」或 Enter；可一次新增多字，重複字自動合併。
- 每個字顯示成「台 ×」等獨立標籤，點 × 只移除該字。全部移除後恢復完整字庫轉換。
- 設定全站共用，只保存在本機；新增／移除立即套用已啟用的分頁。未啟用的網站保持原狀。
